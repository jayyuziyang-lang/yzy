## 微信兼容性处理（已自动完成）

在发布前已对HTML做了以下兼容性转换：

| 转换内容 | 原因 |
|---------|------|
| CSS Grid → `<table>` 布局 | 微信剥离 `display:grid` |
| CSS Flex → `inline-block` + `text-align:center` | 微信剥离 `display:flex` |
| `rgba()` → 纯 hex 色值 | 微信剥离 rgba |
| `box-shadow` → 移除 | 微信剥离阴影 |
| `linear-gradient` → 纯色背景 | 微信剥离渐变 |
| `calc()` → 固定值 | 微信不支持 calc |
| `letter-spacing` → 移除 | 微信不支持 |
| 7张图片 → 微信CDN托管 (`mmbiz.qpic.cn`) | 本地图片微信无法加载 |

## 操作步骤

### 准备工作：安装浏览器插件（只需做一次）

微信原生编辑器在2025年更新后移除了「源代码」模式入口，需要安装插件来粘贴HTML。

**推荐：壹伴助手**（yiban.io）或 **公众号编辑助手**（Chrome应用商店搜索）

安装后刷新公众号后台，编辑器工具栏会多出「编辑源代码」或「HTML」按钮。

### 每次发布步骤

1. 打开 [微信公众号后台](https://mp.weixin.qq.com) → 登录
2. 确认进入的是**订阅号**后台（不是小程序），左上角可切换
3. 左侧菜单：**内容与互动** → **草稿箱** → **新建图文消息**
4. 在编辑器中：
   - **方法A（有插件）**：点击插件提供的「HTML」或「编辑源代码」按钮 → 全选 → 粘贴（HTML已在剪贴板中）
   - **方法B（备选）**：在Chrome打开 `article-wechat-final.html` 文件 → Ctrl+A全选 → Ctrl+C → 回到编辑器Ctrl+V（粘贴为富文本）
5. 在微信编辑器中逐段检查排版效果，重点检查：
   - 3列数据卡片是否正常显示（如"~200颗 / ~3,500颗 / ~5,000颗"）
   - 2列卡片是否左右排列（如"蓄水 / 放水"）
   - 7张图片是否全部加载
   - 公司信息表格是否清晰
6. 上传**封面图**（从 `charts/` 目录选择，推荐 market_share.png）
7. 填写**摘要**（建议：一颗米粒大小的电容如何决定千亿算力——MLCC产业链全景深度解读）
8. 作者栏：**小财**
9. 点击「保存为草稿」→ 手机扫码「预览」
10. 在手机上确认：排版/图片/链接/表格 → 回到电脑端 → 点击「发布」

## 常见问题排查

| 问题 | 解决方案 |
|------|---------|
| Ctrl+V粘贴无效 | 装壹伴插件，用HTML模式粘贴 |
| 3列数据变成竖排 | 可能需要用插件HTML模式重新粘贴 |
| 图片不显示 | 检查微信CDN链接是否过期（图片URL是 `mmbiz.qpic.cn`） |
| 表格有灰色边框 | 微信编辑器会自动加边框，属正常现象 |
| 圆角消失 | 微信不支持 `border-radius`，卡片会变成直角 |
